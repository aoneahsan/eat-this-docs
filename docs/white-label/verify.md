# Verify a licence

Open the [verify page](https://eatthis.aoneahsan.com/verify-license) and paste either:

- **a licence key**, which starts with `EATTHIS-`, or
- **a website address**. We read the licence file that site serves and check the key inside it.

Verification is run by our licensing service. A check shows the company, the domains, the type of licence and the
date updates run to. It never shows an email or a price.

| Answer | What it means |
|---|---|
| Active | The licence is valid |
| Being set up | It's paid, and we're setting the copy up |
| Revoked | The licence was ended under its terms |
| No licence with this key | We didn't issue that key |
| Names a different domain | The site's licence file is for another domain |
| No licence file | The site doesn't serve one |
